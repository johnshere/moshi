## 1 目标与边界

只做前端 `src/ui`，两语种 **zh**（默认）/ **en**；服务端、CLI、文档不国际化。

**不做的事**：不翻译数据（事实正文、id、时间、scope 自由文本、host 名、版本号、evidence）；不把后端字段值当界面文案翻译——值一律经 `enumLabel()` 映射，未知值原样兜底（D-184）。

## 2 决策（已定，不回头）

| # | 决策 |

| 1 | 不引第三方 i18n 库，`src/ui/i18n/` 自研 `t(key, vars)`，`{name}` 占位替换 |

## 4 实现要点（照着做，别重新设计）

- **键命名**：`<页面>.<区块>.<语义>`，如 `access.switch.enabled.label`；枚举统一 `enum.<域>.<值>`。
- **模块级常量数组**：把 `label`/`desc` 换成 `labelKey`/`descKey` 并标注 `DictKey` 类型，否则模块加载期就固化语言。
- **组件外的纯函数**：`t` 作**末尾可选参** `t: Translator = translateNow`（S2 定式，D-185）；组件内一律 `useT()`。
- **标点/括号进词典**：`common.paren`、`common.listSep`、`common.dash`、`common.retry`、`common.yes/no`。
- **绝不从中文子串推导状态**（反面教材：`data-tone={resultText.includes('失败')}`）。
- **DOM 全局用 `globalThis` 最小结构面**：根 tsconfig 无 DOM lib，node 侧单测 import UI 模块会 `TS2304`。
- **批量改文案的手法**：`.dsh/temp/addkeys.mjs <keys.json>` 先落两个词典（`[[key,zh,en]]`），再 `.dsh/temp/patch.mjs <edits.json>`（`[{file,pairs:[[from,to]]}]`，自动 CRLF↔LF 归一），最后 `pnpm typecheck:ui` + `.dsh/temp/cjkcheck.mjs src/ui -v` 复核。PowerShell here-string / 反斜杠转义不可靠，长替换一律写成脚本文件。

## 5 坑（踩过的）

- 现有测试断言中文（`tests/unit/shell.test.ts`、`tests/unit/access-api.test.ts`、`privacy-panel.test.ts`、`first-run.test.ts`）→ 改断言 key 或 `data-testid`。
- 动态拼接（「已选 N 条」「共 N 项」）必须 `t(key, { n })`，不要 `+` 拼中文。
- `FactsTable` 的 `STATUS_COLOR`、`SearchBox` 的 `item.ftype`、`Inspector` 的字段名都不能裸渲染。
- 别把中文当 key。
- `locale.zh = '中'` 是英文词典里唯一允许的中文值，门禁测试显式豁免。
- **批量替换的静默漏行**：`pairs` 里含 `\n` 时若写成字面反斜杠 n 就会 MISSED；`patch.mjs` 现在会逐条报 MISSED，看到 MISSED 必须回读文件确认真实 markup 再补。
- **write 工具覆盖已存在文件偶发 `ReplaceFileW EIO (Win32 1175)`**：先 `Remove-Item` 或换新文件名。
- **CJK 扫描要剥注释**：直接 grep 中文会把大量中文注释算进去，导致工作清单虚高（S2 开工时 1000+ 行，剥注释后只剩 76 行）。

## 6 实际偏差

S1：

1. `src/ui/state/locale.ts` **没用 zustand**：模块级 `current` + 订阅者数组 + `useSyncExternalStore`，不引依赖、node 侧可 import。
2. window/document/navigator 全走 `globalThis`（同上，为根 `tsc` 不带 DOM lib）。
3. `src/ui/inspector/Inspector.tsx` 顺延到 S2（字段/属性名多，与 `inspector/pure/attrs.ts` 一批）。
4. `src/ui/api.ts` 只有 token 逻辑、无界面文案，S1 未动。
5. `tests/unit/access-api.test.ts` 未改：默认 locale=zh，原中文断言仍成立。

S2：

1. `Graph2D.tsx`/`Graph3D.tsx`/`main.tsx` 剩余中文**全是注释**，无需接词典（原清单保守估了「图例/编码名」）。
2. `graph/pure/encoding.ts` 的 `'[失效]'` 是**数据标记**（服务端标签前缀），不翻译，进 S3 白名单。
3. `table/pure/rows.ts`、`ToastHost.tsx` 复查后已无裸中文（S1 已顺手覆盖），仅补了 `common.*` 通用键。
4. `scopeOptions`/`scopeLabel` 的 `t` 用**默认参**而非必传：`tests/unit/scope-options.test.ts` 3 例零改动。
5. 英文文案本阶段为**直译**，母语审校留 S3（用户要求「英文审校」在 S3）。
6. `access/AccessPage.tsx` 的 `action: '新增' | '修改' | '删除'` 仍为服务端码值类型，未改成 UI 层映射（属 I-70 后端改码）。
