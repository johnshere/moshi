## 1 目标与边界

只做前端 `src/ui`，两语种 **zh**（默认）/ **en**；服务端、CLI、文档不国际化。

**不做的事**：不翻译数据（事实正文、id、时间、scope 自由文本、host 名、版本号、evidence）；不把后端字段值当界面文案翻译——值一律经 `enumLabel()` 映射，未知值原样兜底（D-184）。

## 2 决策（已定，不回头）

| # | 决策 |
| --- | --- |
| 1 | 不引第三方 i18n 库，`src/ui/i18n/` 自研 `t(key, vars)`，`{name}` 占位替换 |
| 2 | 词典用语义 key；`dict.ts`（zh）是 key 的**定义处**，`dict.en.ts` 用 `satisfies Record<DictKey, string>`，缺键**编译期**报错 |
| 3 | 语言存 `localStorage['moshi.locale']`，初值取 `navigator.language`（`en*` → `en`，其余 `zh`） |

| 5 | 枚举值（`ftype`/`epistemic_status`/`kind`/`status`/`turn`/`outcome`/`install`…）走 `src/ui/i18n/enums.ts` |
| 6 | 服务端错误按 `error`/`detail.reason` 码映射，映射不到才回退后端原文 |
| 7 | 纯函数模块（S2 定式，D-185）：翻译函数作**末尾可选参** `t: Translator = translateNow`，默认 zh，组件传 `useT()`、node 单测不传 |
| 8 | 数据契约不译、门禁白名单放行：`'[失效]'` 标签前缀（现仅此一条） |

## 4 实现要点（照着做，别重新设计）

- **键命名**：`<页面>.<区块>.<语义>`，如 `access.switch.enabled.label`；枚举统一 `enum.<域>.<值>`。
- **模块级常量数组**：把 `label`/`desc` 换成 `labelKey`/`descKey` 并标注 `DictKey` 类型，否则模块加载期就固化语言。
- **组件外的纯函数**：`t` 作**末尾可选参** `t: Translator = translateNow`（S2 定式，D-185）；组件内一律 `useT()`。
- **标点/括号进词典**：`common.paren`、`common.listSep`、`common.dash`、`common.retry`、`common.yes/no`。
- **绝不从中文子串推导状态**（反面教材：`data-tone={resultText.includes('失败')}`）。
- **DOM 全局用 `globalThis` 最小结构面**：根 tsconfig 无 DOM lib，node 侧单测 import UI 模块会 `TS2304`。
- **批量改文案的手法**：`.dsh/temp/addkeys.mjs <keys.json>` 先落两个词典（`[[key,zh,en]]`），再 `.dsh/temp/patch.mjs <edits.json>`（`[{file,pairs:[[from,to]]}]`，自动 CRLF↔LF 归一），最后 `pnpm typecheck:ui` + `.dsh/temp/cjkcheck.mjs src/ui -v` 复核。PowerShell here-string / 反斜杠转义不可靠，长替换一律写成脚本文件。

## 5 坑（踩过的）

- 现有测试断言中文（`tests/unit/shell.test.ts`、`tests/unit/access-api.test.ts`、`privacy-panel.test.ts`、`first-run.test.ts`）→ 改断言 key 或 `data-testid`。
- 动态拼接（「已选 N 条」「共 N 项」）必须 `t(key, { n })`，不要 `+` 拼中文。
- `FactsTable` 的 `STATUS_COLOR`、`SearchBox` 的 `item.ftype`、`Inspector` 的字段名都不能裸渲染。
- 别把中文当 key。
- `locale.zh = '中'` 是英文词典里唯一允许的中文值，门禁测试显式豁免。
- **批量替换的静默漏行**：`pairs` 里含 `\n` 时若写成字面反斜杠 n 就会 MISSED；`patch.mjs` 现在会逐条报 MISSED，看到 MISSED 必须回读文件确认真实 markup 再补。
- **write 工具覆盖已存在文件偶发 `ReplaceFileW EIO (Win32 1175)`**：先 `Remove-Item` 或换新文件名。
- **CJK 扫描要剥注释**：直接 grep 中文会把大量中文注释算进去，导致工作清单虚高（S2 开工时 1000+ 行，剥注释后只剩 76 行）。

## 6 实际偏差

S1：

1. `src/ui/state/locale.ts` **没用 zustand**：模块级 `current` + 订阅者数组 + `useSyncExternalStore`，不引依赖、node 侧可 import。
2. window/document/navigator 全走 `globalThis`（同上，为根 `tsc` 不带 DOM lib）。
3. `src/ui/inspector/Inspector.tsx` 顺延到 S2（字段/属性名多，与 `inspector/pure/attrs.ts` 一批）。
4. `src/ui/api.ts` 只有 token 逻辑、无界面文案，S1 未动。
5. `tests/unit/access-api.test.ts` 未改：默认 locale=zh，原中文断言仍成立。

S2：

1. `Graph2D.tsx`/`Graph3D.tsx`/`main.tsx` 剩余中文**全是注释**，无需接词典（原清单保守估了「图例/编码名」）。
2. `graph/pure/encoding.ts` 的 `'[失效]'` 是**数据标记**（服务端标签前缀），不翻译，进 S3 白名单。
3. `table/pure/rows.ts`、`ToastHost.tsx` 复查后已无裸中文（S1 已顺手覆盖），仅补了 `common.*` 通用键。
4. `scopeOptions`/`scopeLabel` 的 `t` 用**默认参**而非必传：`tests/unit/scope-options.test.ts` 3 例零改动。
5. 英文文案本阶段为**直译**，母语审校留 S3（用户要求「英文审校」在 S3）。
6. `access/AccessPage.tsx` 的 `action: '新增' | '修改' | '删除'` 仍为服务端码值类型，未改成 UI 层映射（属 I-70 后端改码；**同日已收口**，见 §7）。

S3：

1. 门禁没用 `.dsh/temp/cjkcheck.mjs` 的手写词法器：它在 JSX 里遇到撇号就会把后续内容当成字符串/注释，误判率不可控；改用 `typescript` 编译器 API（devDependency 已有），零新增依赖且边界准确。
2. 白名单从计划里的 `moshi`、`zh-CN` 收敛为**只有两条真数据契约**（`'[失效]'`、三码值联合类型）——`moshi`/`zh-CN` 是纯 ASCII，本就不会命中门禁，写进白名单只是噪音；新增「白名单文件必须存在」断言。
3. 计划外新增第 4 条门禁用例：中英 `{占位变量}` 集合一一对应（`t()` 缺参只保留 `{name}` 不报错，只有门禁能拦）。
4. 英文审校从「逐条读 `dict.en.ts`」改为「真机逐页截图 + 脚本体检（中英同文 / 首尾空白 / 占位 / 双空格）」：`satisfies` 保证不了译得好，缺空格与截断只有看图才发现。
5. 归档空态的空格没走「词典里加空格」或「词典加 `common.linkGap`」（空串会踩「无空串」断言），改用 CSS `flex + gap`，中英共用。
6. 顺手修了概设 §8.1 的两处陈旧描述（页面清单仍是 5 项、`全局常驻元素` 仍写「顶部搜索」），否则 S2 的顶栏收敛会让文档与实现打架。

## 7 I-70 收口：服务端改码值（2026-11-16，D-187）

**为什么做**：S3 之后残留的中文只剩服务端下发的句子（`plan.reason` / `plan.risk` / `step.note` / `step.action` / 手动安装文案），英文界面里它们仍是中文——`enumLabel` 再映射的前提是**服务端发码不发句**。

**改了什么**：

- `src/app/onboard/install.ts`：新类型 `InstallAction = 'add' | 'update' | 'remove'`、`InstallReasonCode`（6 个码）、`InstallRiskCode = 'reload_plugin_host'`、`InstallStepNote`（3 种 `code` + 数据）；`InstallPlan.reason/risk` 从整句收窄为码；`InstallRecord.reason` 保持自由字符串（错误诊断，不属 I-70）。
- `src/app/onboard/routes.ts`：删除 `MANUAL_HOOK` / `MANUAL_MCP` 两个中文字符串常量（文案进词典）；`GET /hook/api/install/plan` 响应删 `manual` 字段；占位计划 `reason` 改 `hook_emit_missing` / `host_plugin_missing`。
- 词典 +19 键：`enum.installAction.*`（3）、`enum.installReason.*`（6）、`enum.installRisk.reload_plugin_host`、`access.note.*`（3）、`access.manualText.*`（6，多行文案用 `\n` 存）；`enums.ts` 的 `DOMAIN_PREFIX` 加 `installAction` / `installReason` / `installRisk`。
- 新增 `src/ui/access/plan.ts`：线上契约 + 映射函数（`actionText` / `reasonText` / `riskText` / `noteText` / `manualTextKey`），`access/AccessPage.tsx` 与 `shell/OnboardModal.tsx` 共用（此前两处各写一份镜像接口）。
- 兼容：`reason` / `risk` / `note` 类型放宽为 `string`，`onboarding.json` 里上一版存下的中文整句、后端新增未译的码值都原样显示。
