## 根因

- 维度：设计阶段默认 bge-small-zh-v1.5 是 384 维，这是笔误（384 是 bge-small-en / MiniLM 的维度）。P1-28 实测为 512，D-62 改了代码，但「改详设」一栏填的是「否」，文档就一直没同步。**和推理运行时无关**：不论用 ONNX 还是 torch，这个模型都是 512 维。
- 推理栈：D-61 为了躲开 torch 的体积，嵌入改用 ONNX Runtime。但 ORT 自 1.20 起停发训练包，也不能加载 `.pt`，消融还得逐个变体导出，撑不住 P3-03~P3-06 和 P4-02。一旦启用 GAT，torch 就是必装，这时就成了概设 §11 已经否决的「双推理栈」。
